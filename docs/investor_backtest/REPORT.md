## ⚠️ What this backtest can and cannot measure
- **News is a proxy.** No historical headline archive exists for Indian equities, so every backtest run tags `news=proxy` and uses the earnings-day gap/volume signature in place of FinBERT/LLM classification. The news layer is forward-test only until enough real headlines have been persisted to `news_events`.- **Fundamentals only exist from 2022-03-01 00:00:00.** The statement source provides annual periods from 2021 onward, so the F layer is unavailable before that date. Runs that use F are therefore only meaningful from that point on; earlier history exercises the Technical/Regime/News layers alone.- **Defensive sleeve is cash.** LIQUIDBEES and GOLDBEES have no price history in this repo, so when the regime layer cuts exposure the remainder accrues at the configured cash yield instead of tracking those ETFs. The gold sleeve is modelled but not price-accurate.- **Price history starts 2016-09-12**, not 2012. The OHLC archive in `data/raw/ohlc` begins then, so the requested 2012 start is not achievable with clean data.- **Promoter pledge and GNPA are not in the data source.** Both filters are armed in `thresholds.yaml` and enforced wherever data exists, but the vendor endpoint carries neither for Indian names, so names with unknown values pass those two checks by configuration rather than by evidence. See `pledge_required` / `gnpa_required`.
